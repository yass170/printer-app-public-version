# Architecture générale — Printer App

Application consacrée à la préparation et au pilotage de tâches d’impression.

Deux ensembles présentent les rôles d’administration et d’utilisation. Les sous-dossiers exposent les couches applicatives, les interfaces, les services et les tests. Les formats d’impression et les traitements métier sont masqués.

Formats techniques représentés dans la copie : Python, C# / .NET, C, XAML, scripts shell, configuration textuelle.

Cette présentation a été rédigée pour la version publique à partir des catégories de fichiers et de dossiers. Elle ne reproduit aucun document interne et ne décrit pas une application exécutable. Les noms spécifiques ont été remplacés par des noms génériques.
